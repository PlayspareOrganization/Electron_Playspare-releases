# Electron by Playspare: installers

Download the latest version from **[Releases](https://github.com/PlayspareOrganization/Electron_Playspare-releases/releases/latest)**:

- **Windows:** `Electron-by-Playspare-Setup-<version>.exe`. It isn't code-signed yet: if SmartScreen warns you, choose *More info → Run anyway*.
- **macOS:** `Electron-by-Playspare-<version>.dmg`. Drag the app to Applications, open it once, then *System Settings → Privacy & Security → Open Anyway*.

Once installed, the app updates itself from this page. Every update is checked against `SHA256SUMS.txt` before it installs.

This repository holds installers only. The source code is private.
